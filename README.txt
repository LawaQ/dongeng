E-BOOK DONGENG DIGITAL — VERSI OFFLINE
======================================

CARA MEMBUKA
1. Ekstrak seluruh isi file ZIP ke satu folder.
2. Jangan memindahkan atau menghapus folder assets.
3. Buka file index.html menggunakan browser (Chrome, Edge, Firefox, atau browser lain).
4. Pilih halaman melalui daftar halaman atau tombol Sebelumnya/Berikutnya.

KETERANGAN VERSI INI
- Seluruh 30 halaman PDF sumber dipertahankan sebagai gambar halaman beresolusi tinggi.
- Navigasi halaman, daftar isi, indikator progres, dan lompat halaman berjalan secara lokal.
- Tidak membutuhkan koneksi internet dan tidak memuat pustaka eksternal.
- Dapat dibuka dari folder hasil ekstraksi pada laptop dan Android yang mendukung pembukaan file HTML lokal.

BATASAN YANG PERLU DIKETAHUI
- Ini adalah migrasi visual tahap pertama. Teks dan elemen pada halaman masih menjadi bagian dari gambar, belum berupa elemen HTML yang dapat diedit satu per satu.
- Audio, animasi, dan interaksi asli Canva tidak ikut terbawa dari PDF. Fitur tersebut perlu dibangun ulang pada tahap berikutnya.
- Untuk beberapa perangkat Android, pengelola file mungkin tidak menyediakan opsi membuka HTML langsung. Gunakan browser yang mendukung pembukaan file lokal atau salin folder ke penyimpanan perangkat.
- Jangan hanya menyalin index.html; seluruh folder assets wajib disertakan.

SUMBER
PDF e-book Dongeng Digital Bahasa Indonesia Kelas III SD/Fase B yang diberikan pengguna (30 halaman).
